# 12. Протокол взаимодействия № 2
## Добавление услуги к бронированию

## 12.1. Инициатор и получатель

Инициатор: `BookingModule`
Получатель: `ServiceModule`

## 12.2. Назначение

После успешного создания бронирования необходимо зарегистрировать
дополнительную услугу, привязанную к бронированию.

## 12.3. Механизм вызова

Асинхронный вызов через интерфейс: `IBookingServiceService`.

## 12.4. Точка входа

```csharp
Task<ServiceDto> AddAsync(
    AddServiceRequest request,
    CancellationToken cancellationToken);
```

## 12.5. Формат запроса

```json
{
  "bookingId": "f9e8d7c6-4321-8765-dcba-fe0987654321",
  "serviceId": "b2c3d4e5-5678-abcd-1234-ef5678901234",
  "quantity": 2,
  "serviceDate": "2026-10-02T08:00:00"
}
```

## 12.6. Успешный ответ

```json
{
  "id": "c3d4e5f6-9012-cdef-5678-0123456789ab",
  "bookingId": "f9e8d7c6-4321-8765-dcba-fe0987654321",
  "serviceId": "b2c3d4e5-5678-abcd-1234-ef5678901234",
  "name": "Завтрак",
  "price": 500.00,
  "quantity": 2,
  "status": "Added"
}
```

## 12.7. Ошибки

| Код | Описание |
|-----|----------|
| BOOKING_NOT_FOUND | Бронирование не найдено |
| SERVICE_NOT_FOUND | Услуга не существует |
| INVALID_QUANTITY | Некорректное количество |
| SERVICE_ALREADY_ADDED | Услуга уже добавлена к бронированию |

Пример ошибки:

```json
{
  "success": false,
  "errorCode": "SERVICE_NOT_FOUND"
}
```

## 12.8. Таймаут

Максимальное ожидаемое время выполнения: 3 секунды.

## 12.9. Повторная отправка

Повторный запрос допускается только после проверки того, что услуга
для данного бронирования ещё не добавлена.
`BookingId` + `ServiceId` используется для предотвращения создания
дублирующих записей.

## 12.10. Аутентификация

Внутренняя аутентификация между модулями не требуется.
Доступ к операции добавления услуги предварительно проверяется
на уровне API.

## 12.11. Версия контракта

`ServiceBookingContract v1`

## 12.12. Пример обмена

```
BookingModule
      │
      │ AddAsync(...)
      ▼
ServiceModule
      │
      │ Проверка бронирования
      │ Проверка услуги
      │ Добавление записи
      ▼
ServiceDto
      │
      ▼
BookingModule
```
